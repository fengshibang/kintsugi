# 目标格式为 lni 源码

**状态:部分修订(Superseded in part by ADR-0004 + ticket 09)**

插件操作 w3x2lni **lni 源码格式**的目标地图(`war3map.j` 为可编辑文本)。选 lni 而非 `.w3x` 直操作,契合 rouge_lua 现有工作流(其 `map/` 即 lni 源码);代价是用户需先把地图解包成 lni。

## 修订:工具链捆绑

**原决策**:不捆绑 w2l,用户自行用 w2l 解包 `.w3x` / 编译。选不捆绑,为避免 w2l 工具链的重量。

**修订后(贴 ADR-0004 自包含)**:插件捆绑完整 w3x2lni 工具链到 `assets/tools/`,导入时拷到目标 `<map_root>/tools/`,目标无需另备 w2l 即可自编译。

**修订理由**:
1. **自包含可分发(ADR-0004)**:框架更新需重新打包,工具链同理;捆绑后目标拿到即可编译,无需外部依赖
2. **降低使用门槛**:用户不必另装 w2l,导入即用
3. **重量可接受**:w3x2lni + jasshelper + rsa 共 ~80M,排除临时目录(backups/logs)后体积合理
4. **MoeHero 专属剥离**:7 个 MoeHero 专属 py + test_selector_pool.lua + __pycache__ 已排除,不污染通用工具链

**保留部分**:仍要求目标是 lni 源码格式(`war3map.j` 为可编辑文本),不直操作 `.w3x` 二进制。

## 冲突策略

- 目标 `tools/` 已存在且含 `w3x2lni/w2l.exe` → **跳过**(用户可能已自定义或升级)
- 目标不含 → **全量拷贝**
- 部分存在 → 按文件粒度跳过已存在的(避免覆盖用户定制)

## 关键约束

- `w3x2lni/config.ini` 含通用配置(无项目特定路径),可直接用
- `运行.lua` 已参数化:无 `arg[2]` 时扫 `root` 下第一个 `*.w3x`,有 `arg[2]` 则指定地图名
- `语法检查.lua` 已参数化:`arg[2]` 指定 script 目录名(默认 `'map'`),`--watch` 可放任意位置
- `ydwe.lua` 用注册表查 YDWE 路径,通用
